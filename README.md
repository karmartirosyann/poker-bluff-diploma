## Ներածություն

**Թեմայի արդիականությունը։** Պոկերը թերի տեղեկատվությամբ խաղ է. խաղացողը չի տեսնում հակառակորդի քարտերը և պետք է որոշում ընդունի միայն նրա գործողությունների հիման վրա։ Հենց դրա համար պոկերը հարմար մոդելային խնդիր է հավանականությունների տեսության, խաղերի տեսության և մեքենայական ուսուցման համար։ Հակառակորդի բլեֆը ժամանակին նկատելը կարևոր է, որովհետև դրանից է կախված՝ պետք է արդյոք վճարել (call) խաղադրույքի դիմաց, թե ոչ։

**Աշխատանքի նպատակը։** Կառուցել մաթեմատիկական մոդել, որը հակառակորդի խաղադրույքի հիման վրա գնահատում է այն հավանականությունը, որ դա բլեֆ է։

**Խնդիրներ։**
1. Ուսումնասիրել պոկերի հիմնական հասկացությունները և բլեֆի տեսական մոդելը։
2. Ստեղծել (սիմուլացնել) տվյալներ, որտեղ հայտնի է՝ հակառակորդը բլեֆ է արել, թե ոչ։
3. Կառուցել բազային Բայեսյան մոդել։
4. Կառուցել մեքենայական ուսուցման մոդել (լոգիստիկ ռեգրեսիա) և համեմատել բազային մոդելի հետ։
5. Հետագայում ավելացնել Մարկովի թաքնված մոդել (HMM) գործողությունների հաջորդականության համար։

**Հետազոտության օբյեկտը՝** Texas Hold'em No-Limit պոկերի river փուլում կատարված խաղադրույքները։
**Հետազոտության մեթոդները՝** Բայեսի բանաձև, խաղերի տեսության տարրեր, լոգիստիկ ռեգրեսիա, Python (pandas, numpy, scikit-learn)։

## Գլուխ 1. Տեսական հիմունքներ

### 1.1 Խաղի կանոններ և հիմնական հասկացություններ

Texas Hold'em-ում յուրաքանչյուր խաղացող ստանում է 2 փակ քարտ, իսկ սեղանին աստիճանաբար բացվում են 5 ընդհանուր քարտեր՝ flop (3), turn (1), river (1)։ Յուրաքանչյուր փուլից հետո կատարվում են խաղադրույքներ։ Այս աշխատանքում մենք նայում ենք միայն **river** փուլը, քանի որ այդ ժամանակ բոլոր քարտերն արդեն բացված են և նոր քարտ չի գալու. դա խնդիրը դարձնում է ավելի պարզ։

Օգտագործվող նշանակումներ.

| Տերմին | Նշանակություն |
|---|---|
| Pot (P) | բանկում եղած գումարը |
| Bet (B) | խաղադրույքի չափը |
| bet_ratio = B/P | խաղադրույքը՝ բանկի մասերով |
| Value bet | ուժեղ ձեռքով խաղադրույք՝ շահելու համար |
| Բլեֆ | թույլ ձեռքով խաղադրույք՝ հակառակորդին թողնելու (fold) համար |
| Showdown | քարտերի բացում փուլի վերջում |

### 1.2 Ի՞նչ է բլեֆը

Բլեֆը այն խաղադրույքն է, որը կատարվում է այնպիսի ձեռքով, որը showdown-ում հավանաբար կպարտվի։ Այսինքն՝ խաղացողը փորձում է հակառակորդին համոզել, որ իր ձեռքը ուժեղ է։ Տարբերում են.
- **մաքուր բլեֆ (pure bluff)՝** ձեռքը գրեթե երբեք չի շահում,
- **կիսաբլեֆ (semi-bluff)՝** ձեռքը դեռ կարող է բարելավվել (river-ում այլևս չկա, դրա համար մենք միայն մաքուր բլեֆի մասին ենք խոսում)։

### 1.3 Pot odds և բլեֆի օպտիմալ մասնաբաժին

Եթե հակառակորդը խաղադրույք է արել B, իսկ բանկում արդեն P է, ապա վճարելու համար մեզ պետք է ներդնել B, որպեսզի հնարավոր շահենք P + B։ Վճարումը անտարբեր է (շահույթը 0), երբ մեր շահելու հավանականությունը հավասար է

$$\frac{B}{P + 2B}.$$

Խաղերի տեսության մեջ (GTO մոտեցում) խաղացողը պետք է բլեֆ անի հենց այդքան հաճախությամբ իր խաղադրույքների մեջ.

$$\alpha = \frac{B}{P + 2B} = \frac{b}{1 + 2b}, \quad b = \frac{B}{P}.$$

Օրինակ՝ եթե b = 0.5 (կես բանկ), ապա α = 0.5/2 = 25%, իսկ եթե b = 1 (ամբողջ բանկ), ապա α = 1/3 ≈ 33%։ Այսինքն՝ ավելի մեծ խաղադրույքի դեպքում թեորիապես կարելի է ավելի հաճախ բլեֆ անել։ Սա կօգտագործենք որպես **բազային մոդել**։

### 1.4 Բայեսի բանաձևը

Մեզ հետաքրքրում է հավանականությունը, որ խաղադրույքը բլեֆ է, եթե տեսել ենք այդ խաղադրույքը.

$$P(\text{բլեֆ} \mid \text{խաղադրույք}) = \frac{P(\text{խաղադրույք} \mid \text{բլեֆ}) \cdot P(\text{բլեֆ})}{P(\text{խաղադրույք} \mid \text{բլեֆ}) P(\text{բլեֆ}) + P(\text{խաղադրույք} \mid \text{value}) P(\text{value})}$$

որտեղ P(բլեֆ)-ը նախնական (apriori) հավանականությունն է, իսկ պայմանական հավանականությունները գնահատվում են տվյալներից։

## Գլուխ 2. Տվյալները և խնդրի ձևակերպումը

Իրական hand history տվյալներում բլեֆի պիտակը հայտնի է միայն այն ձեռքերի համար, որոնք հասել են showdown-ի (մյուս դեպքում հակառակորդը fold է արել և քարտերը չենք տեսնում)։ Սա **ընտրանքի շեղում (selection bias)** է, և այս խնդիրը պետք է քննարկվի աշխատանքում։

Այս փուլում ես օգտագործել եմ **սիմուլյացիա**, որտեղ իմ ձեռքում է պիտակը։ Սիմուլյացիայի կանոնները.
- Ձեռքի ուժը `strength` ~ Uniform(0, 1)։
- Եթե `strength > 0.70`՝ խաղացողը անում է value bet։
- Եթե `strength < 0.25`՝ 50% հավանականությամբ բլեֆ է անում, իսկ մնացած դեպքերում check է։
- Միջին ուժի ձեռքերով (0.25–0.70) check է, դրանք չենք դիտարկում։
- Խաղադրույքի չափը ընտրվում է {0.5; 0.75; 1.0}-ից, ընդ որում value bet-երը միջինում ավելի մեծ են, իսկ բլեֆերը՝ ավելի փոքր։
- Լրացուցիչ հատկանիշներ՝ `wet_board` (վտանգավոր սեղան) և `in_position` (դիրքում է)։

**Բլեֆի պիտակ՝** `is_bluff = 1`, եթե խաղադրույքը արվել է թույլ ձեռքով։

### Կոդ՝ տվյալների գեներացիա (`simulation.py`)

```python
"""Պոկերի river-փուլի պարզեցված սիմուլյացիա՝ բլեֆի տվյալներ ստանալու համար."""
import numpy as np
import pandas as pd


def generate_hands(n=20000, seed=42):
    rng = np.random.default_rng(seed)
    strength = rng.uniform(0, 1, n)          # ձեռքի ուժը [0, 1]
    wet_board = rng.integers(0, 2, n)        # 1՝ վտանգավոր սեղան (draw-եր կան)
    in_position = rng.integers(0, 2, n)      # 1՝ խաղացողը դիրքում է

    rows = []
    for i in range(n):
        s = strength[i]
        if s > 0.70:                         # ուժեղ ձեռք՝ value bet
            bet, bluff = True, 0
            size = rng.choice([0.5, 0.75, 1.0], p=[0.2, 0.4, 0.4])
        elif s < 0.25 and rng.random() < 0.5:  # թույլ ձեռք՝ բլեֆ
            bet, bluff = True, 1
            size = rng.choice([0.5, 0.75, 1.0], p=[0.4, 0.4, 0.2])
        else:
            continue                         # check, այս դեպքը չենք դիտարկում
        rows.append((s, wet_board[i], in_position[i], size, bluff))

    return pd.DataFrame(rows, columns=[
        "strength", "wet_board", "in_position", "bet_ratio", "is_bluff"])
```

## Գլուխ 3. Մոդելներ

### 3.1 Բազային մոդել (GTO բանաձև)

Բլեֆի հավանականությունը գնահատվում է միայն խաղադրույքի չափով՝ α = b / (1 + 2b)։

```python
"""Բայեսյան բազային մոդել՝ հիմնված pot odds-ի վրա."""
import numpy as np


def gto_bluff_share(bet_ratio):
    """Թեորիական բլեֆի մասնաբաժին՝ alpha = B / (P + 2B), որտեղ bet_ratio = B/P."""
    return bet_ratio / (1 + 2 * bet_ratio)


def bayes_posterior(bet_ratio, p_bluff_prior, lik_bluff, lik_value):
    """P(բլեֆ | խաղադրույք) Բայեսի բանաձևով."""
    num = lik_bluff * p_bluff_prior
    den = num + lik_value * (1 - p_bluff_prior)
    return num / den
```

### 3.2 Լոգիստիկ ռեգրեսիա

Մոդելը գնահատում է հավանականությունը այսպես.

$$P(\text{բլեֆ}) = \frac{1}{1 + e^{-(w_0 + w_1 \cdot b + w_2 \cdot \text{wet} + w_3 \cdot \text{pos})}}$$

Գործակիցները գտնվում են առավելագույն ճշմարտանմանության մեթոդով (scikit-learn)։

### 3.3 Գնահատման չափանիշներ

- **ROC-AUC՝** որքան լավ է մոդելը տարբերում բլեֆը value bet-ից (0.5՝ պատահական, 1՝ իդեալական)։
- **Log-loss՝** գնահատում է հավանականությունների որակը։
- **Accuracy՝** ճիշտ դասակարգումների մասնաբաժինը։

### Կոդ՝ փորձի գործարկում (`run.py`)

```python

print(df.groupby("bet_ratio").is_bluff.mean().round(3))

X = df[["bet_ratio", "wet_board", "in_position"]]
y = df["is_bluff"]
Xtr, Xte, ytr, yte = train_test_split(X, y, test_size=0.3, random_state=1, stratify=y)

p_base = gto_bluff_share(Xte["bet_ratio"].values)
print("\nԲազային (GTO) AUC:", round(roc_auc_score(yte, p_base), 3),
      "logloss:", round(log_loss(yte, p_base), 3))

lr = LogisticRegression().fit(Xtr, ytr)
p_lr = lr.predict_proba(Xte)[:, 1]
print("Լոգիստիկ ռեգրեսիա AUC:", round(roc_auc_score(yte, p_lr), 3),
      "logloss:", round(log_loss(yte, p_lr), 3),
      "accuracy:", round(accuracy_score(yte, p_lr > 0.5), 3))
print("Գործակիցներ:", dict(zip(X.columns, lr.coef_[0].round(3))))
```

### Ստացված արդյունքները

Սիմուլյացիայի արդյունքում ստացվեց **8525** խաղադրույք, որոնցից բլեֆ է **29.6%**-ը։

| Խաղադրույքի չափ (b) | Բլեֆի մասնաբաժին |
|---|---|
| 0.50 | 46.0% |
| 0.75 | 30.3% |
| 1.00 | 16.4% |

| Մոդել | ROC-AUC | Log-loss |
|---|---|---|
| Բազային (GTO) | 0.342 | 0.629 |
| Լոգիստիկ ռեգրեսիա | 0.649 | 0.572 |

Լոգիստիկ ռեգրեսիայի accuracy-ն՝ **0.704**։ Գործակիցները. `bet_ratio` = −2.746, `wet_board` = 0.037, `in_position` = 0.024։

### Արդյունքների վերլուծություն

1. **Բազային մոդելի AUC-ն 0.5-ից փոքր է (0.342)։** Դա սխալ չէ. GTO բանաձևը ասում է, որ մեծ խաղադրույքի դեպքում բլեֆի մասնաբաժինը ավելի մեծ է, իսկ մեր սիմուլյացիայի հակառակորդը բլեֆ անում է հիմնականում **փոքր** խաղադրույքներով։ Այսինքն՝ հակառակորդը խաղում է ոչ GTO-ի համաձայն (exploitable), և թեորիական մոդելը դառնում է հակառակ ուղղությամբ։ Սա լավ ցույց է տալիս, որ իրական հակառակորդների վրա միայն թեորիան բավարար չէ։
2. **Լոգիստիկ ռեգրեսիան** սովորել է այդ կախվածությունը (`bet_ratio`-ի գործակիցը բացասական է) և ստացել է AUC = 0.649։
3. `wet_board`-ի և `in_position`-ի գործակիցները գրեթե զրո են, որովհետև սիմուլյացիայում դրանք չեն ազդում բլեֆի վրա։ Սա մոդելի ճիշտ աշխատանքի նշան է (չի «հորինում» կախվածություն, որը չկա)։
4. Արդյունքը կախված է սիմուլյացիայի ենթադրություններից, ուստի իրական տվյալների վրա թվերը տարբեր կլինեն։
